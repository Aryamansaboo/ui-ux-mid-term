# Where Did My Complaint Go?

Midterm project — UX Research & Information Architecture — Vijaybhoomi University

**Problem statement:** Hostel students lack transparency about what happens to their maintenance complaints after submission — they can't tell if it's been received, who's handling it, or what progress has been made.

This repo is the full research trail behind that problem: proto-persona → real interviews → persona → empathy map → journey map → core pain point → user stories → feature inventory → card sort → V1 IA → tree test → revised IA → MoSCoW → DFV matrix → MVP. No UI screens — this is research, sensemaking, and information architecture only.

## View it
Open `index.html` in a browser, or visit the published GitHub Pages link: **https://aryamansaboo.github.io/ui-ux-mid-term/**
